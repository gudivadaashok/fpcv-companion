Binary Images, Interactively

Turn an image into black and white, find each object in it, and measure where each one is, which way it points and how round it is.

Pick a sample below or use your own photo. All processing happens in your browser, so your image never leaves your computer. Follow along with the Binary Images lectures by Shree Nayar in First Principles of Computer Vision.

Choose an image

Each sample shows a different part of the pipeline. Images with dark objects on a plain, bright background work best.

01

Threshold: gray to binary

Each pixel becomes 1 (object) or 0 (background) depending on which side of the threshold T its brightness falls. Drag on the histogram or use the slider.

128

The rule

b(x, y) = 1 if I(x, y) < T, otherwise 0

Otsu's method picks the T that best separates the histogram into two groups, by maximizing the variance between them. If the lighting is uneven, no single T works for the whole image. Try the “Uneven light” sample to see this.

02

Find objects, then measure them

Connected-component labeling gives each group of touching 1-pixels its own label. For each object, the area, centroid and second moments then give its size, position, orientation and roundedness. Click an object to see its numbers.

The formulas

A = ΣΣ b(x, y) x̄ = (1/A) ΣΣ x·b ȳ = (1/A) ΣΣ y·b

a = ΣΣ x′² b b′ = 2 ΣΣ x′y′ b c = ΣΣ y′² b (x′ = x − x̄, y′ = y − ȳ)

E(θ) = a sin²θ − b′ sinθ cosθ + c cos²θ tan 2θ = b′ / (a − c)

E(θ) is the second moment, the sum of squared distances from the object's pixels to a line at angle θ through the centroid. The θ that minimizes it is the object's orientation. Roundedness = Emin / Emax: 1 for a circle or square, close to 0 for a thin line. θ is measured counter-clockwise from the x-axis, with y pointing up.

03

How sequential labeling works

The algorithm scans the image row by row. Each object pixel looks only at neighbors it has already visited. If none has a label, it starts a new one. If two different labels meet, it records them as equivalent, and a second pass merges them. Click cells to draw your own image.
