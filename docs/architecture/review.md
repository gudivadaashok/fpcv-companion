# Consistency review: 20 existing pages

Scope: every page in `CHAPTERS` (common.js:5-26) that exists, plus `index.html`. Pages were not edited. Method: scripted checks over all `*.html` (nav argument, footer, header, viewport, labels, `aria-pressed`, duplicate helpers, duplicate inline CSS, timers, `Math.random`) plus reading the hot paths.

## Clean (no action)

- All 20 pages call `nav("<own file>.html")` with the correct filename, have `<header class="site">`, `<footer class="wrap site">` and `footer()`, a viewport meta, `lang="en"`, one `h1`, and load `site.css` then `common.js`.
- All `.seg` buttons in the pages carry `aria-pressed`. All range inputs and selects have a `<label for>` or `aria-label`. (neural-networks.html:90 looks unlabelled to a regex but sits inside a `<label>`.)
- Every page that animates uses `setTimeout`/`rAF` coalescing; no page blocks on input events with unbounded work except as noted.

# New pages review: face-detection.html and active-illumination.html

Method: read both pages against `docs/specs/`, `face-detection.md`, `active-illumination.md` and decisions.md section 4; ran both in Chromium (fonts blocked, 1000 px and 375 px). Results: no `pageerror`, no console errors, no horizontal overflow at 375 px, nav and pager correct. Numbers measured: FD scan at 104,515 windows (winMin 24, step 1.1, stride 1) takes 102 ms with NN and 7 ms with SVM; default scan finds 2 / 0 / 2 boxes on Two faces / Texture / Mixed with both classifiers, each box IoU above 0.7 against the drawn face. AI: scene rebuild plus all stages about 39 ms (baseline slider); 8-pattern binary decode is 100% exact on the noise-free plane; Gray mean column error is at or below binary in all 9 scene/noise combinations; median depth error on the plane is 0.47% noise-free, 0.8% (Gray) at the default noise 12.
