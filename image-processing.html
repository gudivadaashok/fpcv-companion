The mapping

Equalization uses the cumulative histogram as f, which spreads the brightness levels so each is used about equally. The output histogram becomes roughly flat.

02

Convolution with a kernel

A linear shift-invariant system is fully described by its kernel h. Each output pixel is a weighted sum of the input pixels around it. Click any pixel in the output to see the exact sum.

2.0

Kernel h

The sum

g(i, j) = Σm Σn f(m, n) · h(i − m, j − n)

Kernels whose weights sum to 1 (box, Gaussian) keep the overall brightness. Kernels whose weights sum to 0 (Laplacian, Sobel) respond only to change, so their output is shown with gray as 0, darker as negative and brighter as positive.

Why they differ

Gaussian averages everything in the window, so it spreads noise around and blurs edges. Median takes the middle value of the window, which discards extreme outliers. That makes it the best choice for salt and pepper noise. Bilateral averages only neighbors with similar brightness (within about σr), so it smooths flat regions while keeping edges sharp.

04

Filtering in the frequency domain

The Fourier transform writes an image as a sum of sinusoids. Low frequencies (center of the spectrum) hold smooth shading, and high frequencies (outside) hold edges and fine detail. Multiplying the spectrum by a mask is the same as convolving the image.

20

Things to notice

A sharp low-pass mask causes ripples (ringing) next to edges, because its convolution kernel in the image domain is a sinc function with many side lobes. A smooth Gaussian mask avoids this, because a Gaussian transforms into another Gaussian. A high-pass mask keeps only edges and texture.
