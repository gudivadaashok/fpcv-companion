Neural Networks, Interactively

A neuron weighs its inputs, adds a bias, and squashes the sum. Wire many together and train them by gradient descent, and they carve out decision regions that no straight line can. Convolution layers do the same thing with small shared filters, which is why they suit images.

All training runs in your browser, with the forward pass and backpropagation written from scratch. Follows the Neural Networks lectures.

The perceptron

One neuron with a hard threshold. It classifies a point \(\mathbf{x}\) by the sign of \(\mathbf{w}\cdot\mathbf{x} + b\), so its decision boundary is a line. Click the canvas to add points, and click an existing point to remove it. Then step through the learning rule.

The rule

\[ \hat{y} = \operatorname{sign}(\mathbf{w}\cdot\mathbf{x} + b); \qquad \text{if } y\,(\mathbf{w}\cdot\mathbf{x} + b) \le 0:\quad \mathbf{w} \leftarrow \mathbf{w} + \eta\, y\,\mathbf{x}, \quad b \leftarrow b + \eta\, y \]

A mistake pulls the line toward the missed point: the weight vector tilts toward a missed +1 point, and away from a missed −1 point. If the two classes can be separated by a line, this procedure stops after a finite number of updates. Press "Make XOR data" and run it. XOR cannot be separated by any line, so the perceptron never settles. The run stops after 300 updates.

What the training does

\[ a^{(l)} = f\big(W^{(l)} a^{(l-1)} + b^{(l)}\big), \qquad p = \sigma\big(W^{(L)} a^{(L-1)} + b^{(L)}\big), \qquad \text{loss} = -\operatorname{mean}\big[\, y \ln p + (1-y)\ln(1-p) \,\big] \]
\[ \delta^{(L)} = p - y, \qquad \delta^{(l)} = \big(W^{(l+1)\top} \delta^{(l+1)}\big) \odot f'\big(z^{(l)}\big), \qquad \frac{\partial\, \text{loss}}{\partial W^{(l)}} = \operatorname{mean}\big[\, \delta^{(l)}\, a^{(l-1)\top} \,\big] \]

Each epoch uses all 200 training points at once. The update uses the Adam optimizer, a gradient step with running averages that makes the slider range forgiving. Plain gradient descent would need a much longer run for the spiral. A separate set of 200 points, never trained on, gives the held-out numbers. Try 2 hidden layers with 16 neurons on the spiral, and give it a few thousand epochs. With 1 neuron, XOR cannot be solved at all. With 2 it often can.

02

Convolution, ReLU and pooling

A convolutional layer slides one small filter over the image. At each position it multiplies the 3×3 patch by the filter and adds the products. ReLU then zeroes the negative responses, and max pooling keeps the strongest response in each 2×2 block. Click any output pixel to see the arithmetic.

Filters. The first six are hand-made. The last four are learned: a tiny network trained here to tell horizontal, vertical and two diagonal line orientations apart. Training…

At the selected pixel

The equations

\[ \mathrm{out}(x, y) = b + \sum_j \sum_i K(i, j)\, I(x + i,\, y + j), \qquad i, j \in \{-1, 0, 1\} \]
\[ \mathrm{relu}(v) = \max(0, v), \qquad \mathrm{pool}(x, y) = \max \text{ of the } 2{\times}2 \text{ block at } (2x, 2y) \]

Strictly this is cross-correlation, which is what CNN libraries compute and call convolution. A true convolution flips the kernel first. The output is 2 pixels smaller each way because the filter stays inside the image. Pooling halves the size and keeps a response even if the feature moves by a pixel. Learned filters usually look like the hand-made ones: oriented edges and blobs.

Draw a digit

A small network learns to read digits, and you can test it. It trains in this page on synthetic digits: pen-drawn skeletons and system fonts, with random rotation, slant, scale, thickness and noise. It has never seen real handwriting, so a drawn digit is a harder test than the held-out score suggests. Several digits are split apart first, then read one by one.

The network

196 pixels \(\to\) 48 ReLU neurons \(\to\) 10 outputs, with softmax and cross-entropy loss:

\[ p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}, \qquad \text{loss} = -\ln p_{\text{true}} \]

The score is measured on 500 synthetic digits that the network never trained on. The training and held-out digits come from the same generator, so the score is optimistic for real handwriting. Digits 1 and 7, or 4 and 9, are the usual confusions.

Several digits. Threshold the pad, \(I > \tau\), then label connected components as in the Binary Images lecture. Components whose x-ranges overlap by more than half the narrower one are merged, so a digit drawn in several strokes stays whole, and specks are dropped. The groups are sorted left to right and each is read separately. Digits that touch fuse into one component and are read as one, so leave a gap.

Preprocessing. Training images and pad drawings go through the same steps: crop to the ink bounding box, scale so the longest side is 11 of 14 pixels, average over the source area each output pixel covers (anti-aliased, not point sampling), and shift so the center of mass \(\bar x = \sum I\,x \,/\, \sum I\) (likewise \(\bar y\)) sits at the middle.
