Neural Networks, Interactively

A neuron weighs its inputs, adds a bias, and squashes the sum. Wire many together and train them by gradient descent, and they carve out decision regions that no straight line can. Convolution layers do the same thing with small shared filters, which is why they suit images.

All training runs in your browser, with the forward pass and backpropagation written from scratch. Follows the Neural Networks lectures.

00

The perceptron

One neuron with a hard threshold. It classifies a point x by the sign of w·x + b, so its decision boundary is a line. Click the canvas to add points, and click an existing point to remove it. Then step through the learning rule.

The rule

ŷ = sign(w·x + b) if y·(w·x + b) ≤ 0: w ← w + η y x, b ← b + η y

A mistake pulls the line toward the missed point: the weight vector tilts toward a missed +1 point, and away from a missed −1 point. If the two classes can be separated by a line, this procedure stops after a finite number of updates. Press "Make XOR data" and run it. XOR cannot be separated by any line, so the perceptron never settles. The run stops after 300 updates.

What the training does

a⁽ˡ⁾ = f(W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾), p = σ(W⁽ᴸ⁾ a⁽ᴸ⁻¹⁾ + b⁽ᴸ⁾), loss = −mean[ y ln p + (1−y) ln(1−p) ]

δ⁽ᴸ⁾ = p − y, δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾ᵀ δ⁽ˡ⁺¹⁾) ⊙ f′(z⁽ˡ⁾), ∂loss/∂W⁽ˡ⁾ = mean[ δ⁽ˡ⁾ a⁽ˡ⁻¹⁾ᵀ ]

Each epoch uses all 200 training points at once. The update uses the Adam optimizer, a gradient step with running averages that makes the slider range forgiving. Plain gradient descent would need a much longer run for the spiral. A separate set of 200 points, never trained on, gives the held-out numbers. Try 2 hidden layers with 16 neurons on the spiral, and give it a few thousand epochs. With 1 neuron, XOR cannot be solved at all. With 2 it often can.

02

Convolution, ReLU and pooling

A convolutional layer slides one small filter over the image. At each position it multiplies the 3×3 patch by the filter and adds the products. ReLU then zeroes the negative responses, and max pooling keeps the strongest response in each 2×2 block. Click any output pixel to see the arithmetic.

Filters. The first six are hand-made. The last four are learned: a tiny network trained here to tell horizontal, vertical and two diagonal line orientations apart. Training…

At the selected pixel

The equations

out(x, y) = b + Σⱼ Σᵢ K(i, j) · I(x + i, y + j), i, j ∈ {−1, 0, 1}

relu(v) = max(0, v) pool(x, y) = max of the 2×2 block at (2x, 2y)

Strictly this is cross-correlation, which is what CNN libraries compute and call convolution. A true convolution flips the kernel first. The output is 2 pixels smaller each way because the filter stays inside the image. Pooling halves the size and keeps a response even if the feature moves by a pixel. Learned filters usually look like the hand-made ones: oriented edges and blobs.
